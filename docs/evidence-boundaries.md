# 引用与事实边界收尾

2026-11-17。保持主Agent与三个专家，未增加核验Agent。本轮针对上一轮遗留的口径引用、方式扩展推断、最终回答引用定位做修复。

## 变更

- 新增M开头的sales_rules证据：来源为应用提供的统计口径与允许表结构，明确不是SQL查询结果。Q仍只表示实际销售查询。schema工具保存该证据，交给主Agent单独引用；附录明确区分二者。
- M不计入实际来源覆盖，不可替代Q满足销售任务；仅取得schema时，即使正常返回或因预算停止，也不能标SUCCEEDED/PARTIAL冒充已查销售，任务为FAILED。
- 在专家交接时检查高影响方式/服务词是否出现在本条supports原文中，覆盖课件、录播、直播、陪练、批改、保过、永久、一对一；丢失“通常”限定也拒绝。失败项留在审计事件、从交接中过滤，并标PARTIAL。
- 最终回答按段落/表格单元格检查同处引用，不以整份文档中别处出现某个词替代本条摘录。统计能力/缺失字段说明需要M引用，不能只挂Q。明确的“本次未取得/未确认”分句不当作服务承诺；同段其他肯定句仍检查。
- 过长或有边界问题时共用最多一次主模型修订，仍流式输出并重置旧草稿。修订后复查，未解决则PARTIAL；不会自动给句子换引用、硬截断或编造补充证据。
- 更新验收脚本，sales_rules只允许出现在含销售的请求中，重放SQL时跳过口径；自动追加的PARTIAL说明改为覆盖来源、引用及格式问题。

这是有限的字面边界检查，不是通用语义核验：同词异义、否定含义、课程班期归属及每项金额语义仍需逐项复核。对未列出的同义词不保证检测，显式未知分句也有解析局限。只检查词语存在并不能证明完整承诺成立。
