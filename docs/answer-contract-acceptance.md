# 回答收尾与冻结新题验收

2026-11-17，版本r13。主Agent及三个专家保持不变。**本轮完成了实现、回归和一次冻结新题验收，尚未达到所有回答质量问题已解决。**

## 本轮改动

- 输出约定读取阿拉伯数字及中文一至十的句数要求，超过句数与超长/引用问题共用既有的一次修订，修订后仍不满足则PARTIAL。当前尚未识别“两句话”；新题H02人工确认实际输出两句。
- 引用检查从整行细化到中文句号、分号划分的局部单元。较长中文引语须在就近引用的通过交接摘录中出现；句后紧跟引用和表格共享证据列均支持。不会自动换引用。
- 这仍是有限规则：不能验证任意改述是否被原文支持；有引号的课程名也可能被当作原文引语，造成表格单元格误报。新题H06已记录这个问题，未为通过该题继续改规则。
- unknowns保留对象和字段，转为“本次尚未确认该对象此项信息”的统一解释，避免把专家未经验证的缺失原因传成全页/全库不存在。额外交接retrieval_status，说明已取得来源与字段通过检查是两回事，避免过滤事实后编造“没取得正文”。
- 收敛专家conditions和主Agent回答范围：只提取所问字段，固定句数问题不加标题、总结或未问服务；平台答疑问题不展开历史班级清单。它属于提示约束，真实输出仍会违反，验收不将其写成必然保证。
- 验收脚本新增`--catalog`，独立题库仍保存代码/题目哈希、任务、证据、SQL重放、独立参考和复核，已有记录不自动重提交。
