# 架构与统计约定

## 实际入口

运行 `korean.server:app`；前端入口 `frontend/src/ResearchApp.tsx`。应用8000与本机RAG只读网关8899通过HTTP通信，独立虚拟环境；地址可配置。

前端以多轮对话组织请求，消息单独落chat_messages，关联不可变task_id；每轮沿用thread_id。输入缺少课程或完整调研所需的竞品时，规则解析器先保存澄清消息，不调用付费模型。支持明确课程ID/全名、竞品冒号格式和ISO日期；不声称具备通用自然语言意图解析。前端移除范围与文件选项，回答默认无文件，完成后可导出MD/PDF，导出不重新调用模型。CSS使用color-scheme与light-dark自动跟随系统，浏览器无需刷新即可响应系统主题变化。

主Agent规划并整合报告。network子Agent只使用网络搜索；course子Agent只调用资料检索；sales子Agent先读取schema，再选择SQL逐步分析。子Agent用LangChain create_agent编译，主Agent用DeepAgents create_deep_agent调度；关闭默认general-purpose助手，避免额外角色。文件生成由服务统一处理。内置模型文件工具关闭，报告目录由程序管理。

network/course通过Pydantic结构交付原子事实、对象、适用状态、限制和逐字摘录；中间件过滤错误来源、不可见摘录及越角色对象。sales交接直接取实际工具表格，避免模型重写数字。超长正文最多一次主模型压缩，保留SSE并重置旧草稿，仍超限则PARTIAL。实现及真实复测边界见 [结构化专家交接](structured-handoff.md)。原文存在校验不等于事实推理核验。

运行职责拆分为 `runtime.py`（Agent组装与整合）、`prompts.py`（提示词）、`tools.py`（业务工具）、`budget.py`（调用预算）、`streaming.py`（正文与草稿）；交接约束在 `handoff.py`，持久化在 `store.py`。详见 [代码讲解](code-guide.md)。

销售数字最终由 `report_tables.py` 直接呈现实际工具结果与逐行查询引用，主模型用一次位置标记留出表格位置，继续负责课程比较和解释。流式转换器处理跨块标记、重置与最终草稿一致性；篇幅预算包含整张表和程序口径。遗漏/重复标记或模型重写表格会触发一次修订，未解决为PARTIAL。详见 [销售表与新题验收](report-stability.md)。

## 数据及来源

MySQL：courses、orders、refunds；SQLite：任务、事件、证据、产物索引；另一个SQLite保存LangGraph检查点；Milvus由已有RAG服务管理。

自家文档和销售记录为合成资料；竞品在live模式为实际搜索结果。offline模式三路均使用固定合成样例，不调用LLM，不是多Agent效果评测。

课程ID K01/K02/K03用于关联。RAG中共享章节不强行绑定为某一课程事实，保留章节和原文，让课程Agent区分。当前目录只含一份课程版本；如更换课程政策，须建立新版本数据集，不能覆盖历史证据。

## 统计

北京时间，左闭右开区间。成交订单按付款时间计数，不因退款删除；收款按付款时间，退款按实际退款时间。区间净收款=区间收款−区间退款，不是会计收入，可能为负。

客单价=区间收款/成交订单数；无订单时null。退款率按付款区间的订单集合，在指定截止时间前退款的去重订单数/成交订单数；不能把当月退款笔数除以当月订单数代替。上期为零时增长率显示未知，保留绝对变化。SQL输出截断时禁止宣称全量分析。

来源ID由工具创建：W网络、D课程文档、Q销售查询、M应用定义的销售口径与数据能力。M不能代替Q满足销售查询覆盖。最终引用必须属于当前任务；检查ID、覆盖、摘录及有限方式/服务词的同处引用，语义支持仍需人工评测。网络摘要与正文分别记录，采集时间不等于活动生效时间。细节见 [引用边界收尾](evidence-boundaries.md)。

## 运行与失败

一个Uvicorn worker，同时2个任务。每任务600秒，60次模型调用、40次工具调用、10次搜索；达到任一限制停止，保留已获取证据和未完成说明；可在回答后导出。工具仅对网络传输、429或5xx最多重试1次，各次尝试均计数。模型SDK自动重试关闭，回调在每次模型请求前检查预算，包括框架摘要调用。Token未知显示未知，费用仅按配置的每百万Token单价估算，搜索费用不计。

事件先落SQLite再推送。当前前端使用SSE，先读取快照再处理增量；兼容WebSocket接口仍保留，刷新或断连后HTTP可重读。相同thread只能有一个运行/排队任务。重试生成新task_id和新检查点，旧结果保留；会话最近两份完成报告作为非权威上下文，不复用旧证据ID。服务重启后未完成任务标记INTERRUPTED，不自动续跑付费请求。

单来源失败时返回缺失说明，报告状态PARTIAL；没有任何可用证据则FAILED。异常不返回密钥或供应商原始HTTP响应。仅绑定本机，不提供公网多用户权限保证。

完整报告要求三类来源；API可指定research_scope为network、course或sales，单项任务只检查对应来源。离线演示固定走完整链路，不用于测量Agent路由质量。
