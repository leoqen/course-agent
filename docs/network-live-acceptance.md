## 发现的限制及后续修改

本次证据有较多重复及不相关网页，且未取得竞品详情正文。报告把未检索到字段表述为“未公开”，把不同课程价差推断为价格冲突，这些判断缺乏充分依据；SUCCEEDED只代表执行与来源覆盖达标，不代表语义全部正确。

验收后已收紧提示：区分“本次未检索到”和“未公开”；不同课程价差不直接算冲突；不能把搜索请求视为已经访问详情页；comparison不输出销售章节。为减少正文带来的上下文开销，返回模型的每条网页正文上限6000字符并明确标记截断，证据库最多保留30000字符。长网页的后半部分不会自动进入模型，可能需要更精确的补查。

上述修改已做本地测试，没有为验证提示词反复提交付费任务。原验收报告保留原样，不追改成修改后的效果。随后已完成独立销售MySQL与三路协作验收，见 [sales-live-acceptance.md](sales-live-acceptance.md)；尚未进行多案例准确率或多Agent对照实验。
